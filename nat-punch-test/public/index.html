ICE-конфигурация

По умолчанию используются публичные STUN-серверы Google — это не сервер для хостинга, а «зеркало»: WebRTC узнаёт через него свой публичный IP для проброса портов. Можно очистить поле (будет чистый LAN-тест) или вставить свой STUN/TURN (формат [{"urls":"stun:host:port"}]).

Как проверить

  1. Запусти сервер (start.bat) и открой его с ПК.
  2. Нажми «Создать комнату», скопируй ссылку и отправь себе на телефон (например в Telegram).
  3. Открой ссылку на телефоне — он сам войдёт в комнату по коду из ссылки.
  4. Если оба в одной Wi-Fi — будет тип пары host (локальная сеть).
  5. Чтобы проверить именно NAT punchthrough — пробрось порт 8080 наружу (playit.gg / ngrok) и повтори с телефона в мобильной сети: появится тип srflx или prflx — это и есть пробитый NAT, трафик идёт напрямую.
  6. Если не соединилось и с включённым TURN появился relay — NAT не пробился, данные шли через релей.

Совет: у тебя или у друга включённых одновременно может быть только один клиент в комнате. Комната одноразовая — для нового теста создавай новую.
