# GDD: ThreadScape

## Концепция

Visual Novel + Social Media Sim + Psychological Horror. Вы — модератор нового соцсети в альтернативном 2009-м. Вы решаете, какой контент одобрять, с кем дружить, и постепенно понимаете, что пользователи сети — не те, за кого себя выдают. Некоторые из них вообще не существуют.

**Играбельные аналоги:** Blooming Panic (6,211 ratings, 4.9★ — VN в стиле Discord-сервера) + last seen online (horror puzzle — "сёрфинг чужого компа") + Online Obsession (3,701 ratings, 4.8★) + The Choicer Voicer (top seller — голосовые мини-игры).

## Почему это будет успешно

- **Доказанный формат:** VN в оболочке мессенджера/соцсети — один из самых успешных поджанров на itch.io
- **Актуальная тема:** Соцсети, приватность, онлайн-идентичность — боль 2020-х
- **Уникальная механика:** Модерация контента как геймплей (вместо просто выбора реплик)
- **Ретро-ностальгия:** Эстетика early 2010s соцсетей (ВКонтакте, early Facebook, Tumblr)
- **Вирусный потенциал:** "Choose who gets banned" — идеальный контент для TikTok/YouTube

## Жанр

Visual Novel / Simulation / Horror / Interactive Fiction

## Платформа

Web (HTML5), Windows, macOS

## Целевая аудитория

16-28, аудитория VN и horror на itch.io, фанаты DDLC и аналогичных мета-игр

## Ключевые механики

### 1. Модерация-геймплей
- Игрок видит ленту постов от пользователей
- Каждый пост: одобрить / удалить / забанить пользователя
- Выбор влияет на историю: забаненный пользователь может исчезнуть... навсегда
- Метрики: "Довольные пользователи" vs "Безопасность платформы" — баланс

### 2. Direct Messages
- Пользователи пишут модератору (игроку) в личку
- Развитие отношений: дружба, романтика, конфликт
- Некоторые персонажи — боты или "мёртвые души"
- Визуальные эффекты: сообщения "исчезают", чаты деформируются

### 3. Mystery Layer
- За пользователями стоят реальные люди (или не люди)
- Постепенное раскрытие: кто-то использует платформу для слежки
- Конспирологические теории среди пользователей оказались правдой
- Тёмная тайна платформы: создатель скрыл что-то в коде

### 4. Meta-уровень
- Игра иногда "выходит за пределы соцсети"
- Появляется "рабочий стол" игрока с файлами
- Игрок находит "документы разработчика" — лор в лоре
- Финал зависит от всех решений за игру

## Структура контента

| Глава | Описание | Ключевой момент |
|-------|----------|-----------------|

## Визуальный стиль

- **UI как геймплей:** Экран разделён на "ленту", "чаты", "панель модератора"
- **Эстетика 2009:** Скевоморфизм, градиенты, "Web 2.0" стиль
- **Глитчи:** Постепенная деградация UI по мере раскрытия тайны
- **Портреты персонажей:** Anime-стиль с элементами реалистичности
- **Цветовая палитра:** Основная — голубой/белый (чистота), потом — красный/чёрный (опасность)

## Звук

- Ambient электроника (losing-my-mind vibes)
- Уведомления мессенджера как ритмический элемент
- Искажение звука при horror-моментах
- Lo-fi музыка "из колонок персонажей"

## Технологии

- Ren'Py или Godot (VN + UI система)
- Кастомный UI для имитации соцсети
- Aseprite / Clip Studio для артов

## Монетизация

- **Free:** Глава 1 + 2
- **Paid:** $5.99 — полная игра (5 глав)
- **Доп.收入:** $2.99 — DLC с дополнительными персонажами

## Конкурентные преимущества

- Формат "соцсеть как игра" — проверенная формула, но с уникальным механическим поворотом
- Высокий replay value (множество концовок, скрытые персонажи)
- Идеально для стримов и контента
- Низкая стоимость производства (текст + 2D арты + UI)

## Примерная оценка времени разработки

3-4 месяца (1-2 человека)

## Риски и митигация

| Риск | Решение |

| Слишком похоже на Blooming Panic | Добавить horror/mystery слой — это ключевое отличие |
