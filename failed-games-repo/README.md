# Реестр проваленных геймдев-проектов

Открытый реестр геймдев-проектов, которые провалились или не достигли успеха.
Цель — учиться на чужих ошибках и не повторять идеи, которые уже не сработали.

## Как развернуть

1. Сайт хостится бесплатно на **GitHub Pages** (Settings → Pages → Source: ветка main, корень).
2. База данных — `data/failed-projects.json`. При добавлении записей файл обновляется и все пользователи видят новые данные.

## Защита от спама и скама

- **Turnstile** (Cloudflare) — антибот-капча на форме.
- **Лимит 5 записей/день** на пользователя.
- **Honeypot** — скрытое поле, которое заполняют боты.
- **Санитизация контента** — удаление HTML/скриптов (защита от XSS) и нейтрализация ссылок (защита от скам-кликов).
- **Модерация** — записи одобряются перед публикацией в базе.

## Перед публикацией

В `submit.html` заполните настройки:

- `FORM_ACTION` — endpoint Formspree (ваш email при этом скрыт от пользователей).
- `data-sitekey` — Site Key виджета Cloudflare Turnstile.

## Структура

- `index.html` — главная страница со статистикой и базой проектов.
- `submit.html` — форма добавления провалившегося проекта.
- `data/failed-projects.json` — база данных проектов.
