# GDD: SortGrim

## Концепция

Horror-симулятор сортировки. Вы — призрак, запертый в лиминальном пространстве библиотеки между мирами. Ваша задача — сортировать книги, документы и артефакты, чтобы восстановить порядок и освободиться. Но каждая сортировка раскрывает фрагменты жуткой истории.

**Играбельный аналог:** Sort the Court! (10,965 ratings, 4.7★) + The Grand Book Archive: Tidy Up (тренд "инкрементальная сортировка") + last seen online (horror puzzle) + лиминальные пространства (Your Happy Place, топ продаж).

## Почему это будет успешно

- **Пересечение двух трендов:** "cozy organizing/sorting" (инкременталки с сортировкой — главный новый тренд 2026) + horror (стабильно продаётся)
- **Низкая сложность разработки:** Механики сортировки просты, контент — текст и арты
- **Вирусный потенциал:** Контраст "милая сортировка" → "жуткий хоррор" идеален для YouTube/TikTok
- **Браузерная доступность:** HTML5, играется на itch.io без скачивания
- **Модель монетизации:** Free demo + paid chapters ($3-5)

## Жанр

Horror / Simulation / Incremental / Puzzle

## Платформа

Web (HTML5), Windows

## Целевая аудитория

16-30, любители хоррора и уютных игр, аудитория itch.io (основная — VN и horror фанаты)

## Ключевые механики

### 1. Система сортировки
- Игрок получает стопки книг/артефактов/документов
- Классификация по категориям (жанр, эпоха, "опасность")
- Чем точнее сортировка, тем больше фрагментов истории раскрывается
- Инкрементальная система: unlocks новых категорий, расширение библиотеки

### 2. Narrative Layering
- Каждая правильно отсортированная категория — фрагмент лора
- Неправильная сортировка触发 скрытые скримеры или альтернативные ветки
- 5 концовок на основе того, какие книги куда попали

### 3. Ambient Horror
- Фоновая музыка меняется в зависимости от жанра сортируемых книг
- Тени в проходах между стеллажами
- Книги иногда "двигаются" сами, когда игрок отворачивается
- HUD-элементы (таблица сортировки) медленно деформируются

### 4. Meta-механика
- Игра "знает", что игрок сортирует — появляется консоль с подсказками от "другого призрака"
- В определённый момент игра просит игрока отсортировать... свои собственные воспоминания (флешбеки)

## Структура контента

| Глава | Описание | Механика |
|-------|----------|----------|
| 1. Вестибюль | Туториал, базовая сортировка книг | Yes/No сортировка (как Sort the Court!) |
| 2. Читальный зал | Сортировка документов с шифрами | Drag & drop с категориями |
| 3. Архив запретных | Книги "опасны" — сортируй по уровню угрозы | Risk/reward: неправильная сортировка = скример |
| 4. Зеркальный зал | Сортируешь зеркальные копии — что的真实? | Mind-bending пазлы |
| 5. Выход | Финальная сортировка: выбор судьбы | Моральная дилемма |

## Визуальный стиль

- **Пиксель-арт** с элементами 3D-пространства (как в retro horror)
- Палитра: глубокие синие/фиолетовые + тёплый жёлтый свет ламп
- Лиминальные пространства: бесконечные коридоры, повторяющиеся стеллажи
- Влияние: Backrooms, Клуб Завтраков (DDLC), ANATOMY

## Звук

- Ambient drone + ASMR-звуки перелистывания страниц
- Динамическая система: музыка адаптируется к жанру сортируемых книг
- Подсказки "другого призрака" — искажённый голос через помехи

## Технологии

- Godot 4 или Phaser.js (для веба)
- Aseprite для артов
- Audacity/FMOD для звука

## Монетизация

- **Free:** Глава 1 (туториал)
- **Paid:** $3.99 — полная игра (5 глав)
- **DLC:** $1.99 — "Потерянные страницы" (альтернативные главы)

## Конкурентные преимущества

- Уникальная механика (horror + organizing — такой комбинации практически нет)
- Низкий порог входа (интуитивная сортировка)
- Высокий replay value (5 концовок, скрытые фрагменты)
- Идеально под формат itch.io (короткие сессии, браузер)

## Примерная оценка времени разработки

2-3 месяца (1 человек) / 1-1.5 месяца (команда 2-3)

## Риски и митигация

| Риск | Решение |
|------|---------|
| Сортировка может быть скучной | Добавить randomized элементы, mini-events, narrative hooks |
| Horror может быть слишком subtle | Добавить "hard horror" ветку для любителей скримеров |
| Низкая конверсия в paid | Сделать Chapter 1 очень engaging, оставить клиффхэнгер |
