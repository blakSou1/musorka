# Ветер и трава — дань Ghost of Tsushima

Интерактивное поле травы в духе Ghost of Tsushima: ветер гонит волны по полю,
трава раздвигается вокруг курсора, свист поднимает вихрь.

## Запуск

Нужен любой браузер (Chrome / Edge / Firefox). Двойной клик по `start-server.bat`,
затем откройте **http://localhost:8000**.

> Файл нельзя открывать напрямую двойным кликом по `index.html` — браузер блокирует
> ES-модули через `file://`.

Three.js и все зависимости лежат локально в `vendor/` — интернет не нужен.

## Управление

| Действие | Эффект |
| --- | --- |
| Движение мыши | ветер раздвигает траву за курсором |
| Зажать ЛКМ | «бег» сквозь поле — сильный разлёт травы |
| Пробел или кнопка СВИСТ | дух ветра — вихрь раздвигает траву + свист |
| Колесо мыши | приблизить / отдалить |

## Возможности (в духе Ghost of Tsushima)

- **Tuft-инстансинг** — 1 инстанс = пучок из 3 лезвий → ~3x больше травы при тех же затратах
- **Чанки + фрустум-каллинг** — поле режется на 64 чанка, невидимые не рисуются
- **LOD с переходом** — дальние чанки переключаются на упрощённые пучки + растворение в земле
- **Тень травы на земле** — затемнение под густой травой, запечённое в цвета рельефа (без shadow pass)
- **Вытаптывание** — след от курсора остаётся примятым на пару секунд
- **Ветер** — скроллящийся шумовой поток + порывы
- **Клэмпинг** — травинки одной ячейки имеют общие цвет/высоту/жёсткость
- **Освещение** — затенение по наклону лезвия, fake AO, закатное солнце на кончиках
- **Интерактив** — мышь гонит траву, ЛКМ «бег», Пробел/СВИСТ поднимает вихрь

## Оптимизация

- По умолчанию bloom выключен — чтобы включить, откройте `http://localhost:8000/?fx=1`
- Количество травинок подстраивается под мощность машины (ядра CPU)
- На слабых GPU (нет WebGL2) трава автоматически прореживается

## Структура

- `index.html` — страница, импорты Three.js с CDN
- `css/style.css` — оформление интерфейса
- `js/main.js` — сцена, камера, постобработка (bloom), ввод
- `js/grass.js` — 44 000 экземпляров травы (InstancedMesh + шейдеры):
  порывы ветра, бегущие волны, раздвигание вокруг курсора, вихрь свиста
- `js/terrain.js` — холмистый рельеф с вершинными цветами
- `js/sky.js` — градиентное небо с солнцем (закатный час)
- `js/particles.js` — пыльца в воздухе
- `js/audio.js` — процедурный ветер и свист (WebAudio)
- `vendor/` — локальные Three.js r160 и дополнения (OrbitControls, постобработка)
