# GDD: MossHeart

## Концепция

Cozy incremental/organizing game в мире мелких зверей. Вы — барсук-инженер, строящий подземный город для лесных жителей. Копайте тоннели, стройте комнаты, собирайте ресурсы, привлекайте жителей. Медленный, уютный, бесконечный прогресс.

**Играбельные аналоги:** Serenitrove (3,767 ratings, 4.9★ — "Dig, upgrade, expand... then dig deeper!") + Sort the Court (управление королевством) + инкременталки (Cosmic Forge, The Grand Book Archive — главный тренд 2026 на itch.io) + A Short Hike (4,375 ratings, 4.9★ — cozy exploration).

## Почему это будет успешно

- **Инкременталки — #1 тренд 2026:** "The Grand Book Archive: Tidy Up", "Cosmic Forge", "Clown Hole" — все в new & popular
- **Cozy игры стабильно популярны:** "Cute" тег в топ-10 трендов itch.io
- **Малый объём производства:** Инкременталки не требуют сложного арта или анимаций
- **Долгосрочная вовлечённость:** Инкременталки идеальны для "永远在线" модели
- **Нет прямого конкурента:** Cozy + incremental + animal в браузере — уникальная комбинация

## Ключевые механики

### 1. Копание и строительство
- Кликайте на землю для копания тоннелей
- Каждый тоннель — определённый тип (жилой, рабочий, склад)
- Расширение: от одной норы до целого подземного города
- Автоматическое копание (после upgrades)

### 2. Экономика ресурсов
- Ресурсы: глина, камень, мoss, грибы, семена, вода
- Каждый ресурс нужен для разных построек
- Цепочки крафта: глина → кирпич → стена → комната
- Автоматизация: нанимайте рабочих ( mole-助手)

### 3. Жители
- Лесные звери приходят в город (ёжи, белки, лягушки, совы)
- Каждый вид жителей даёт уникальный бонус
- Жители могут "устраивать события" (мини-игры)
- Счастливые жители привлекают новых

### 4. Season System
- 4 сезона меняют доступные ресурсы и事件
- Зимой: меньше ресурсов, но можно строить "тёплые" комнаты
- Весной: размножение жителей
- Летом: строительство на поверхности
- Осенью: сбор урожая

### 5. Decoration & Expression
- Декорируйте комнаты мебелью из найденных предметов
- Каждый житель имеет "предпочтения" в декоре
- Фотоальбом: автоматические скриншоты вашего города

## Прогрессия

| Этап | Описание | Unlock |
|------|----------|--------|
| 1. Нора | Барсук один, копает первую яму | Базовые ресурсы |
| 2. Подземелье | Появляются первые жители | Крафт, торговля |
| 3. Город | Автоматизация, много жителей | Технологии, исследование |
| 4. Подземная река | Новые биомы, редкие ресурсы | Водные постройки |
| 5. Лесная сеть | Город связан с другими норами | Multiplayer-lite (обмен ресурсами) |

## Визуальный стиль

- **Топ-вид** (как в Stardew Valley для подземелий)
- **Пиксель-арт** тёплых тонов (коричневый, зелёный, жёлтый)
- Милые, простые спрайты зверей
- Анимации копания, строительства, жителей
- Day/night cycle с меняющимся освещением

## Звук

- Lo-fi / acoustic ambient
- ASMR-звуки: копание, строительство, шорох листьев
- Уникальные звуки для каждого вида жителей
- Сезонная смена музыки

## Технологии

- Phaser.js или PixiJS (для веба)
- Godot для мобильных портов
- Простая архитектура данных (JSON для saves)

## Монетизация

- **Free:** Базовая игра (до Этапа 2)
- **Paid:** $2.99 — полная версия
- **IAP (мобайл):** Косметика, декор ($0.99-2.99)
- **Ad-supported:** Опциональная реклама для бонусов

## Конкурентные преимущества

- Уникальная ниша: cozy + incremental + animals
- Мгновенная играбельность (в браузере)
- Низкий порог входа, высокая досада
- Масштабируемость: легко добавлять контент (новые виды, постройки, сезоны)

## Примерная оценка времени разработки

2-3 месяца (1 человек) для MVP, затем итеративно

## Риски и митигация

| Риск | Решение |
|------|---------|
| Инкременталки могут казаться "пустыми" | Сильный narrative layer: история барсука и его семьи |
| Конкуренция с другими incremental | Качественный арт + уникальная тема = выделение |
| Monetization на itch.io ограничена | Двойной релиз: itch.io (free/paid) + Steam (полная версия) |
