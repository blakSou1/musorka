💀 GDD #1: SortGrim

SortGrim

Horror Simulation Incremental Puzzle  |  Web (HTML5), Windows

🎯 Концепция

Horror-симулятор сортировки. Вы — призрак, запертый в лиминальном пространстве библиотеки между мирами. Сортируйте книги, документы и артефакты, чтобы восстановить порядок и освободиться. Каждая сортировка раскрывает фрагменты жуткой истории.

Аналоги: Sort the Court! (10.9K ratings, 4.7★) + The Grand Book Archive (инкрементальный тренд) + last seen online (horror puzzle) + лиминальные пространства.

✅ Почему это будет успешно

  • Пересечение двух трендов: "cozy organizing" (главный тренд 2026) + horror (стабильно продаётся)
  • Низкая сложность: Механики сортировки просты, контент — текст и арты
  • Вирусный потенциал: Контраст "милая сортировка" → "жуткий хоррор" = YouTube/TikTok
  • Браузерная доступность: HTML5, без скачивания
  • Цена: Free demo + $3.99 полная игра

🎮 Ключевые механики

  • Система сортировки: Классификация книг/артефактов по категориям. Инкрементальная прогрессия: unlocks новых категорий, расширение библиотеки.
  • Narrative Layering: Правильная сортировка = фрагмент лора. Неправильная = скримеры или альтернативные ветки. 5 концовок.
  • Ambient Horror: Музыка меняется по жанру книг. Тени в проходах. Книги "двигаются". HUD деформируется.
  • Meta-механика: Консоль с подсказками от "другого призрака". Финал: сортировка своих воспоминаний.

💬 GDD #2: ThreadScape

ThreadScape

Visual Novel Simulation Horror Interactive Fiction  |  Web (HTML5), Windows, macOS

🎯 Концепция

VN + Social Media Sim + Psychological Horror. Вы — модератор нового соцсети в альтернативном 2009-м. Решаете, какой контент одобрять, с кем дружить. Постепенно понимаете: некоторые пользователи не существуют.

Аналоги: Blooming Panic (6.2K ratings, 4.9★) + last seen online + Online Obsession (3.7K, 4.8★) + The Choicer Voicer (top seller).

✅ Почему это будет успешно

  • Доказанный формат: VN в оболочке мессенджера — успешный поджанр на itch.io
  • Актуальная тема: Соцсети, приватность, онлайн-идентичность
  • Уникальная механика: Модерация контента как геймплей
  • Ретро-ностальгия: Эстетика early 2010s (ВКонтакте, Tumblr)
  • Вирусный потенциал: "Choose who gets banned" = TikTok контент

🎮 Ключевые механики

  • Модерация: Лента постов → одобрить / удалить / забанить. Выбор влияет на историю. Метрики: "Довольные" vs "Безопасность".
  • Direct Messages: Развитие отношений в личке. Некоторые — боты или "мёртвые души". Чаты деформируются.
  • Mystery Layer: Пользователи ≠ те, за кого себя выдают. Конспирологические теории оказались правдой.
  • Meta-уровень: Игра "выходит за пределы соцсети". Рабочий стол, файлы разработчика. Финал зависит от всех решений.

🌿 GDD #3: MossHeart

MossHeart

Incremental Simulation Cozy Management  |  Web (HTML5), Android, iOS

🎯 Концепция

Cozy incremental/organizing game в мире мелких зверей. Вы — барсук-инженер, строящий подземный город для лесных жителей. Копайте тоннели, стройте комнаты, собирайте ресурсы, привлекайте жителей. Медленный, уютный, бесконечный прогресс.

Аналоги: Serenitrove (3.8K ratings, 4.9★) + Sort the Court + инкременталки (Cosmic Forge, The Grand Book Archive) + A Short Hike (4.4K, 4.9★).

✅ Почему это будет успешно

  • Инкременталки — #1 тренд 2026: The Grand Book Archive, Cosmic Forge, Clown Hole — все trending
  • Cozy стабильно: "Cute" в топ-10 трендов itch.io
  • Малый объём: Инкременталки не требуют сложного арта/анимаций
  • Долгосрочная вовлечённость: Бесконечный прогресс
  • Нет конкурентов: Cozy + incremental + animals в браузере — уникальная комбинация

🎮 Ключевые механики

  • Копание и строительство: Клик на землю → тоннели. Автоматическое копание после upgrades.
  • Экономика: Глина, камень, moss, грибы, семена, вода. Цепочки крафта. Автоматизация (mole-助手).
  • Жители: Ёжики, белки, лягушки, совы. Каждый вид = уникальный бонус. Счастливые привлекают новых.
  • Season System: 4 сезона меняют ресурсы и события. Зимой — тёплые комнаты, весной — размножение.
  • Decoration: Декорируйте комнаты. Фотоальбом автоматических скриншотов города.

⚔️ GDD #4: SoulForge

SoulForge

Roguelike Deckbuilder Action RPG Souls-like  |  Windows, macOS, Linux

🎯 Концепция

Roguelike deckbuilder + Souls-like combat. Карта вашей души определяет стиль боя. Собирайте "фрагменты души", комбинируйте в колоду, сражайтесь с боссами, олицетворяющими ваши слабости.

Аналоги: Pawned Souls (trending新品) + HoloCure (5.2K, 4.9★) + Friday Night Funkin' (12.4K) + The Ruins of Calaworm (top seller).

✅ Почему это будет успешно

  • Souls-like + deckbuilder: Pawned Souls trending — спрос подтверждён
  • Roguelike структура: Высокий replay value, контент для стримов
  • Уникальная механика: "Карта души" = олицетворение внутреннего мира
  • Визуал: Пиксель-арт + dark fantasy — проверенная формула
  • Цена: $7.99 — идеальный price point

🎮 Ключевые механики

  • Soul Cards: Каждая карта — фрагмент души (страх, надежда, ярость, покой). Комбинации = build. Меняет статы + визуал.
  • Souls-like Combat: Пошаговые бои. Stamina management, timing windows. Perfect timing = крит. Phase transitions боссов.
  • Roguelike: Случайные комнаты, карты, боссы. Death = reset, но "мудрость" остаётся. 6 Worlds, Blessings.
  • Narrative Through Combat: Каждый босс = аспект прошлого. Победа = принятие. Финальный босс = "Вы сами".

🌊 GDD #5: Voices Below

Voices Below

Horror Simulation Interactive Fiction Atmospheric  |  Web (HTML5), Windows

🎯 Концепция

Horror-симулятор глубоководной станции. Вы — оператор радара на подводной базе в 1987-м. Ловите аномальные сигналы из глубин океана. Каждый сигнал — нечто нечеловеческое. И они начинают отвечать.

Аналоги: Voices Of The Void (5.8K, 4.9★ — сбор сигналов из космоса) + ANATOMY (top seller) + Feed the Fish ($2, top seller) + Baldi's Basics (top seller).

✅ Почему это будет успешно

  • VotV — хит itch.io: Сбор "сигналов" — доказанно популярная механика
  • Underwater horror — ниша: Subnautica доказал: океан = страх
  • Ретро 80-е: CRT мониторы, VHS — главный horror-тренд
  • Низкая сложность: Основной геймплей — радар + текст
  • Стриминг: Идеально для Twitch (зрители кричат "не смотри!")

🎮 Ключевые механики

  • Радар-интерфейс: Экран радара с волнами. Курсор → аномалия → реакция. Захват → фильтры (frequency analysis).
  • Signal Analysis: Частота, амплитуда, "настроение". Мини-игры: настройка частоты, расшифровка паттернов. Записи людей... и не только.
  • Sanity System: Аномальные сигналы = влияние. Галлюцинации, странные звуки, "друзья" по рации. 3 пути: сопротивление, принятие, трансцендентность.
  • Тайна базы: Секретные документы. Другие операторы... не совсем люди? База — не исследовательская.
  • Dynamic Events: Отключение питания, стук в стену, шторм, blackout.
